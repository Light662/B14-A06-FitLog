# 💪 FitLog — Workout Library

FitLog is a dark, no-nonsense gym companion. Browse a library of lifts, open a
workout for full details, lock it into today's plan or save it for later, and
track the minutes and calories of your day.

## 🛠️ Technologies Used
- Next.js (App Router)
- React (Context API for global state)
- Tailwind CSS
- Lucide React icons
- Deployed on Vercel

## ✨ Features
1. Fully responsive layout for mobile, tablet and desktop
2. Workout library grid with sort by duration, calories or rating, plus search by name or muscle
3. Detailed workout page with specs table and step-by-step instructions
4. "Add to today's plan" (5-lift cap) and "Save for later" with live navbar counters and toast notifications
5. My Plan page with live Exercises / Minutes / Calories totals, Mark as Done and Remove actions
6. Plan and saved data persisted in localStorage
7. Custom 404 page and loading states

## 🚀 Getting Started
```bash
npm install
npm run dev
```
Open http://localhost:3000
